# Manda-Mela

Manda-Mela is a third-person multiplayer number-hunt party shooter built with Unreal Engine 5.8. Each player gets a four-digit number that opponents must read and enter to eliminate them. Game modes include Deathmatch, Team Deathmatch, and Capture the Flag, with bots available for offline play.

## Repository contents

This repository contains the C++ and C# source files from `Source/` and this README. It excludes Unreal project files, configuration, game content, and binary assets such as FBX animations. The source files are therefore not a standalone, buildable Unreal project.

The code targets the `MandaMela` Unreal runtime module. The original project uses Unreal Engine 5.8.
